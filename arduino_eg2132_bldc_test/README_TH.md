# ชุดทดสอบ BLDC + EG2132 ด้วย Arduino Uno/Nano

โค้ดนี้ใช้ตรวจการทำงานเบื้องต้นของอินเวอร์เตอร์สามเฟสใน `SCH_drive_2026-08-24.pdf` หลังเปลี่ยน gate driver ทั้งสามตัวเป็น EG2132 ใช้กับ Arduino Uno/Nano รุ่นคลาสสิกที่เป็น ATmega328P 16 MHz เท่านั้น PWM อยู่ที่ประมาณ 31.37 kHz และเป็น six-step แบบ open-loop จึงเหมาะกับการ bring-up บนโต๊ะทดลอง ไม่ใช่เฟิร์มแวร์ FOC หรือเฟิร์มแวร์ใช้งานจริง

## การต่อสายที่หัว H2

| H2 | สัญญาณในแบบ | Arduino Uno/Nano |
|---:|---|---:|
| 10 | W_HIN | D11 |
| 9 | V_HIN | D10 |
| 8 | U_HIN | D9 |
| 7 | W_LIN | D8 |
| 6 | V_LIN | D7 |
| 5 | U_LIN | D4 |
| 4 | CURRENT_W | A2 |
| 3 | CURRENT_V | A1 |
| 2 | CURRENT_U | A0 |
| 1 | AGND | GND |

ข้อสำคัญ: ถ้าบนบอร์ดมี STM32F405 อยู่ ห้ามต่อเอาต์พุต 5 V จาก Uno เข้าพร้อมกับ R73-R78 ที่ยังติดอยู่ เพราะจะป้อนไฟ 5 V เข้าขา MCU 3.3 V ให้ถอด R73-R78 หรือไม่ลง STM32 ระหว่างทดสอบด้วย Uno ส่วน Arduino ใช้ไฟจาก USB และต่อกับบอร์ดเฉพาะ GND/สัญญาณตามตาราง อย่าผูก 5 V สองแหล่งเข้าหากัน

## สิ่งที่ต้องแก้/ตรวจเมื่อใช้ EG2132

- EG2132 ใช้ pinout เดียวกับสัญลักษณ์เดิม: 1 VCC, 2 HIN, 3 LIN, 4 GND, 5 LO, 6 VS, 7 HO, 8 VB และ HIN/LIN เป็น active-high ทั้งคู่
- ไฟ 12 V ในแบบอยู่ในช่วง VCC ของ EG2132 แต่ควรเพิ่มเซรามิก 100 nF ชิดขา VCC-GND ของไอซีแต่ละตัว ขนานกับ C34-C36
- ควรเพิ่มเซรามิก 100 nF ถึง 1 uF ชิดขา VB-VS ขนานกับ C31-C33 และตรวจทิศ D4-D6/ระยะลูป bootstrap ให้สั้น
- แนะนำใส่ตัวต้านทาน gate-source ราว 10 kOhm ที่ Q1-Q6 เพื่อให้เกตไม่ลอยตอน gate driver ยังไม่มีไฟ
- C25-C30 ค่า 22 nF เป็นโหลดที่เกตค่อนข้างสูง ควรเริ่มประกอบแบบ DNP แล้วดู ringing และเวลาขึ้น/ลงที่ gate-source ก่อนเลือกค่าจริงร่วมกับ gate charge ของ MOSFET
- ในแบบยังไม่มีเบอร์ Q1-Q6 และ U13-U15 จึงยังตรวจ gate charge, กระแสที่รับได้, gain ของ current sense และแปลง ADC เป็นแอมป์ไม่ได้
- C18-C20 รวมเพียง 6.6 uF ไม่ใช่ bulk DC-link ที่เพียงพอสำหรับมอเตอร์ทั่วไป ต้องมี bulk capacitor/film capacitor, ฟิวส์ และการจำกัดกระแสที่เหมาะกับแรงดันและมอเตอร์จริง
- EG2132 ไม่มีขา enable/fault และ software trip ไม่เร็วพอแทน hardware over-current protection ควรเพิ่มวงจรตัด PWM แบบฮาร์ดแวร์ก่อนทดสอบกระแสสูง

## ลำดับทดสอบที่แนะนำ

1. ยังไม่ต่อมอเตอร์และยังไม่จ่าย VSUPPLY อัปโหลดโค้ด แล้ววัดที่ HIN/LIN ก่อน ทุกขาต้องเป็น LOW หลัง reset
2. จ่ายเฉพาะ 12 V ให้ EG2132 ตรวจ LO เทียบ GND ก่อน จากนั้นจ่าย VSUPPLY เพียง 6-12 V ด้วยแหล่งจ่ายจำกัดกระแสเพื่อดู HO
3. HO ต้องวัดเทียบ VS ของเฟสนั้นด้วย differential probe หรือ isolated probe ห้ามหนีบ ground clip ของออสซิลโลสโคปลง PHASE_U/V/W หรือ HO โดยตรง
4. เปิด Serial Monitor ที่ 115200 baud เลือก line ending เป็น Newline ส่ง `arm` แล้วส่ง `test` เพื่อวนหกสถานะช้า ๆ สำหรับวัด waveform; โหมดนี้ต้องถอดมอเตอร์
5. ตรวจว่าทุก half-bridge ไม่เคยมี HO และ LO สูงพร้อมกัน ตรวจ gate voltage, dead time, ringing และอุณหภูมิก่อน
6. เมื่อต่อมอเตอร์ ให้ตั้ง current limit ต่ำ เริ่มด้วย `duty 8`, `period 10000`, ส่ง `arm` และ `run` ถ้ามอเตอร์สั่นแต่ไม่หมุนให้ `stop` ก่อน แล้วลอง `dir rev` หรือสลับสายมอเตอร์สองเส้น

## คำสั่ง Serial

| คำสั่ง | การทำงาน |
|---|---|
| `arm` | ปิดทุกเกต, วัดค่า current zero และเตรียมพร้อม |
| `test` | วน six-step ช้า ๆ สำหรับออสซิลโลสโคป (ไม่ต่อมอเตอร์) |
| `run` | เริ่ม six-step open-loop พร้อมไล่ความเร็ว |
| `stop` | ปิด HIN/LIN ทั้งหกทันทีและ disarm |
| `duty N` | ตั้ง duty 1-60% |
| `period N` | ตั้งคาบต่อหนึ่ง commutation step ช่วง 1000-100000 us |
| `dir fwd` / `dir rev` | ตั้งทิศขณะหยุด |
| `trip N` | ตั้ง software trip เป็นผลต่าง ADC counts; `0` คือปิดการป้องกันนี้ |
| `zero` | วัด current zero ใหม่ขณะหยุด |
| `status` | แสดงสถานะและค่า ADC |
| `help` | แสดงรายการคำสั่ง |

ค่า trip เริ่มต้นคือ 80 ADC counts เทียบจากค่า zero ของแต่ละช่อง เนื่องจากแบบไม่ได้ระบุเบอร์/gain ของ U13-U15 ค่านี้เป็นเพียง guard สำหรับ bring-up และยังแปลงเป็นหน่วยแอมป์ไม่ได้
